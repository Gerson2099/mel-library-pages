Perguntas frequentes

O MEL já está disponível no Google Play?

Ainda não. O aplicativo está em preparação para testes e lançamento. Esta página será atualizada quando houver uma versão pública disponível.

Preciso criar uma conta?

Não. A biblioteca local funciona sem login. A Conta MEL Cloud é opcional para recursos de comunidade e conta.

O MEL vende livros?

Não. O MEL organiza a biblioteca e poderá encaminhar o usuário para lojas externas. Compra, cobrança, entrega e atendimento são feitos pela loja escolhida.

Meus arquivos de leitura vão para a nuvem?

Não. Arquivos PDF, CBR e CBZ da biblioteca permanecem no aparelho e não são enviados à MEL Cloud.
