# MEL Public Pages

Static public pages for Google Play requirements:

```text
index.html
privacy.html
account-deletion.html
partners.html
styles.css
assets/
```

Recommended use:

```text
1. Publish these files through GitHub Pages, Netlify, Vercel, or any static host.
2. Use `privacy.html` as the Play Console privacy policy URL.
3. Use `account-deletion.html` as the Play Console account deletion/support URL.
4. Recheck contact e-mail and last-updated date before public release.
5. Keep `partners.html` accurate: list a program as active only after approval
   and after its tracking links are working.
```

If using GitHub Pages from the repository `docs/` folder, the likely paths are:

```text
https://gerson2099.github.io/mel-library-pages/privacy.html
https://gerson2099.github.io/mel-library-pages/account-deletion.html
```

These URLs were confirmed after the GitHub Pages source was configured.
